01. PROJECT OVERVIEW

IOE MASTER là gì?

IOE MASTER là hệ thống ứng dụng trí tuệ nhân tạo nhằm hỗ trợ học sinh THPT học tập, luyện tập và nâng cao năng lực tiếng Anh. Đồng thời, hệ thống cung cấp công cụ quản trị ngân hàng câu hỏi, đánh giá kết quả và theo dõi tiến bộ học tập cho giáo viên.

Hệ thống hướng đến mô hình học tập cá nhân hóa:

Learn – Practice – Assess – Analyze – Improve.

Đối tượng sử dụng: Giáo viên quản trị, giáo viên bộ môn và học sinh lớp 10, 11, 12.

08. AI PROMPT ENGINEERING

Prompt 1: Generate Test

You are an expert English teacher.

Generate an English test for Vietnamese
high school students.

Requirements:
- Grade: {{grade}}
- Topic: {{topic}}
- Number of questions: {{number}}
- Difficulty: {{difficulty}}

Requirements:
- Follow the Vietnamese high school curriculum.
- Ensure linguistic accuracy.
- Provide one correct answer for each MCQ.
- Include answer explanations.
- Return valid JSON only.

Prompt 2: Grade Test

You are an English assessment expert.

Compare the student's answers with
the verified answer key.

Return:
{
  "score": 0,
  "correct": 0,
  "wrong": 0,
  "feedback": []
}

Prompt 3: Analyze Errors

Analyze the student's mistakes.

Identify:
- Vocabulary weaknesses
- Grammar weaknesses
- Reading comprehension weaknesses
- Common error patterns

Suggest specific improvement strategies.
Do not invent student performance data.

Prompt 4: Study Plan

Create a personalized 7-day English
learning plan based on verified weaknesses.

Include:
- Daily learning objectives
- Vocabulary practice
- Grammar exercises
- Reading practice
- Self-assessment

11. MVP QUALITY & SECURITY RULES

Important: AI-generated questions must not be published automatically without validation.
  • Only approved questions can be published.
  • Answer keys must not be exposed to students before submission.
  • Student data must be protected by authentication and access policies.
  • AI scores must be validated against deterministic answer keys.
  • Every attempt must be stored for progress tracking.
  • Teacher approval is required for official learning materials.
  • API keys must be stored in server-side environment variables.
